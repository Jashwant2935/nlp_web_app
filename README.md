# NLP Web Application using Flask and Hugging Face

This project is a Natural Language Processing (NLP) Web Application developed using Python, Flask, HTML, CSS, SQLite, and Hugging Face Transformers. The application allows users to register and log in securely, and then perform different NLP tasks through a simple web interface.

## Features

### User Authentication

* User Registration
* User Login
* SQLite Database Integration
* Duplicate User Checking

### Named Entity Recognition (NER)

The application can identify entities from user input text such as:

* Person Names
* Locations
* Organizations

Example:

* Elon Musk → PERSON
* Google → ORGANIZATION
* India → LOCATION

### Sentiment Analysis

The application analyzes the sentiment of the entered text and predicts whether the sentiment is:

* Positive
* Negative

It also displays the confidence score of the prediction.
